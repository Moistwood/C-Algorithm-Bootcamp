# 蓝桥杯 C++ 省一特训

一个**零依赖、纯静态**的 C++ 算法学习站点，附带一个能真正编译运行的本地评测器。
从「不会写 C++」到「能拿省一」，把 51 个知识专题和 80 道配套题串成一条线。

打开就能看，想跑代码就起一个本地服务。不需要 npm，不需要构建，不需要联网。

## 快速开始

### 只想看内容

双击 `index.html`。全部知识点和题目都能看，只是「运行」按钮不可用。

### 想在站内跑代码（推荐）

1. **装 Python 3.8+**（[官网下载](https://www.python.org/downloads/)，安装时勾选 `Add Python to PATH`）
2. **双击 `启动评测服务.bat`**
3. 浏览器打开 <http://127.0.0.1:8787>

第一次运行如果提示找不到编译器，执行：

```bash
python setup-toolchain.py
```

它会自动下载 w64devkit（MinGW-w64 + GCC 16，约 69 MB）到 `toolchain/`，
解压并生成预编译头。**只用一次，之后不用再管。**

> 如果你本机已经装了 Dev-C++ / Code::Blocks / MSYS2，`judge.py` 会自动找到它们的 g++，
> 不需要跑 setup 脚本。

## 目录结构

```
algo-lanqiao/
├── index.html              入口，单页应用
├── judge.py                本地评测服务 + 静态服务器（Python 标准库，单文件）
├── setup-toolchain.py      一键下载 MinGW 工具链
├── 启动评测服务.bat         Windows 启动脚本
├── start.sh                macOS / Linux / Git Bash 启动脚本
├── assets/
│   ├── style.css           全部样式（深色主题 + 响应式）
│   ├── app.js              渲染引擎：语法高亮、markdown、路由、进度
│   └── judge.js            评测面板前端
└── data/
    ├── knowledge-1..10.js  51 个知识专题
    └── problems-1..7.js    80 道题
```

内容全部是 JS 数据，想加一节或一题，直接在对应文件里追加对象即可，不用改渲染代码。

## 技术说明

- **无构建**。原生 JS + CSS，浏览器直接跑。
- **无 CDN**。语法高亮、Markdown 渲染、代码编辑器都是手写的，断网也能用。
- **真编译**。`judge.py` 调用本机 `g++ -std=c++14 -O2`，参数和蓝桥杯考场一致，
  不是前端模拟执行。
- **进度存在 localStorage**，清浏览器数据会丢，服务端不存任何东西。
- 编译超时 40s，运行超时默认 2s（可调），输出上限 512KB。
